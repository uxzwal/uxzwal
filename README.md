## Featured Projects

### VectorDB — Local AI Engine

> A vector database built from scratch in C++ with HNSW, KD-Tree, and a RAG pipeline powered by local LLMs.

- 3 search algorithms compared side-by-side: HNSW, KD-Tree, Brute Force
- 768D embeddings via Ollama (`nomic-embed-text`) + local generation (`llama3.2`)
- Full REST API + interactive dashboard with PCA scatter plot

**Stack:** `C++` `HNSW` `KD-Tree` `Ollama` `REST API`

[github.com/uxzwal/Your-OWN-AI](https://github.com/uxzwal/Your-OWN-AI)

---

### UPI Offline Mesh

> Offline UPI payments routed through a Bluetooth-style mesh, settled exactly once.

- Hybrid encryption (RSA-OAEP + AES-GCM) — untrusted intermediaries can't read or tamper
- Atomic idempotency (`putIfAbsent`) — duplicate bridge uploads settle **exactly once**
- Full test suite: concurrent duplicate delivery, tampered ciphertext rejection

**Stack:** `Java` `Spring Boot` `RSA-OAEP` `AES-GCM` `Concurrency`

[github.com/uxzwal/UPI_Without_Internet](https://github.com/uxzwal/UPI_Without_Internet)

---

### Jobhunt — AI Job Search Agent

> A personal agent that scans ATS APIs every morning, ranks jobs with LLMs, and emails a daily digest.

- Fetches from Greenhouse, Lever, Ashby public APIs
- 90% LLM cost reduction via regex/location prefilter
- Runs daily via GitHub Actions — `seen.json` cached, not committed

**Stack:** `Python` `LLMs` `GitHub Actions` `ATS APIs`

[github.com/uxzwal/PWP_jobhunt](https://github.com/uxzwal/PWP_jobhunt)

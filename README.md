## About Me

Hey, I am Ujjwal, a BCA student from Bihar who likes clean backend systems, boring deployments, and infra which behaves the same on every machine.

I started with Python, C, C++, and DSA. Now I spend most of my time around FastAPI, Django, Docker, Linux, GitHub Actions, cloud basics, and Kubernetes. I like building small systems, breaking them, fixing them, and then turning the fix into a repeatable workflow.

### My Engineering Taste

- Write code which runs locally and in containers without drama
- Keep configs readable, secrets out, logs useful, and deploy steps repeatable
- Prefer simple APIs, clear folder structure, and practical automation
- Learn by building real things, not by collecting tool names
